نشر Stick Studio على Render
============================

1) ارفع محتويات هذا المجلد إلى مستودع GitHub جديد (Repository).
2) افتح https://render.com وسجّل الدخول باستخدام GitHub.
3) اختر New + ثم Blueprint، واختر مستودع المشروع.
4) Render سيقرأ render.yaml وينشئ خدمة الويب.
5) في إعدادات الخدمة، أضف ELEVENLABS_API_KEY إذا أردت تفعيل الصوت الحقيقي.
6) انتظر اكتمال النشر ثم افتح رابط onrender.com الذي يظهر في لوحة Render.

مهم:
- لا ترفع ملف .env أو مفتاح ElevenLabs إلى GitHub.
- يمكن تجربة واجهة الموقع بدون مفتاح، لكن توليد الصوت الحقيقي يتطلب مفتاح ElevenLabs.
- الخطة المجانية قد توقف الخدمة بعد فترة عدم استخدام، وقد يستغرق أول فتح بعدها بعض الوقت.
- خدمة Render تنشر الخادم؛ لا تتضمن خدمة Claude لتوليد السيناريو التلقائي.
